# How we code without vibe coding

1. Programmer studies written+video lesson and creates own simple practice.
2. Programmer opens assigned function and reads the signature, contract, acceptance.
3. Programmer writes logic personally. AI may give up to 6 graded conceptual hints, not full source code.
4. Programmer writes normal and failure tests. Skips do not count.
5. Partner reviews implementation and verifies claims about source and calculation.
6. Only then merge; record result in `docs/WORK_LOG.md`.
7. No changes to architecture based on hypothetical scores alone. Change when a real test identifies a concrete defect.
