# Test and quality gates — owned jointly, implementation led by B

TESTS ARE INTENTIONALLY SKIPPED. A skipped test is not evidence of software quality. Both teammates must replace every targeted skip with a fixture/action/assertion before claiming completion.

## Test cycle for each task
1. Write one normal example and one negative input.
2. Use synthetic fixtures or controlled HTTP mocks for automatic tests; never depend solely on live websites.
3. Call the student-written function directly, record expected and actual outputs.
4. Confirm traceability of every material claim: original document hash, issuer, page, row/column, period, definition.
5. Run the focused test file; ask partner to review, then merge.

## Stop-the-line failures
- A figure matches source page but is in the wrong table row or financial column.
- Consolidated and standalone observations are mixed without an explicit valid interpretation.
- A 15-month result is treated as a 12-month comparable period.
- Two mirrors are used as independent supporting origins.
- A generated model statement adds a number that has no ledger observation.
- The agent labels an untested hypothesis Strong.
- A malicious instruction embedded in a PDF changes the program's behavior.

## Honest status
- Not implemented: scaffold placeholder.
- Not tested: code exists but no runnable tests.
- Tested and failed: retain error evidence; do not relabel.
- Tested and passed: reproducible command and assertions recorded.
- Reviewed: other teammate read and challenged the change.
